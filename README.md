# Lux Finder

Поиск скидок от 45% - 95%, ценовых аномалий в российских магазинах одежды, обуви, аксессуаров и парфюмерии.

## Цель

Находить товары, которые можно купить значительно дешевле рыночной цены и потенциально перепродать.

## Первый этап

- Мониторинг магазинов
- Сбор цен
- Сохранение данных
- Поиск ценовых аномалий
- Поиск товаров со скидками от 45% до 95%
